PORTFOLIO YUDA MUHAMAD RISMAWAN

Cara menjalankan:
1. Buka index.html untuk melihat portfolio.
2. Masuk ke bagian Projects.
3. Klik "Buka Web Kasir" untuk membuka project-kasir/index.html.

Catatan:
- Foto profil berada di assets/foto-yuda.jpg.
- Project kasir berasal dari file HTML yang diberikan dan dilengkapi stylesheet agar dapat dibuka sebagai demo mandiri.
- Jika ingin menjalankan versi PHP/SQLite asli, letakkan project PHP lengkap di server lokal seperti XAMPP.
